From PDF to useful answer

Start the hosted app, add your provider key, and bring your own text-based PDFs.

Deploy to Streamlit

Open the deployment flow and select this repository, the main branch, and app.py.

Add your API key

In the app's Streamlit settings, add a Groq or OpenRouter key under Secrets. Never put keys in this public repository.

Upload and ask

Upload one or more PDFs, wait for indexing, then ask questions and check the cited pages.

Ready to explore your documents?

Deploy your own private app instance. Your API keys belong in Streamlit Secrets, not on this public project page.
